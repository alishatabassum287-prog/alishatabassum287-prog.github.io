# Jannatul Ferdushi Tabassum Portfolio

This is a framework-free static website built with HTML, CSS, JavaScript, images, and PDF documents. It does not require Next.js, npm, or GitHub Actions.

## Publish with GitHub Pages

1. Extract the ZIP.
2. Upload everything inside this folder to the root of the `main` branch.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.

For the repository `alishatabassum287-prog/alishatabassum287-prog.github.io`, the expected public address is:

`https://alishatabassum287-prog.github.io/`

Do not create a Next.js workflow and do not upload the ZIP file itself. Upload the extracted contents so `index.html` stays in the repository root.

## Local preview

Open `index.html` directly in a browser. Navigation uses page anchors, so every section works without a local server.
